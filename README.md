# Τι μπορώ να κάνω; · ΣΥΝΟΙΔΑ

Ελληνική εφαρμογή κοινωνικών καταστάσεων για παιδιά 5–8 ετών, με θεραπευτή.

[Άνοιγμα εφαρμογής](https://dimitriskatik13-cmd.github.io/koinonikes-katastaseis/)

- 62 καταστάσεις: Σπίτι, Σχολείο, Εξωτερικές δραστηριότητες.
- Τέσσερις επιλογές ανά κατάσταση και δύο εναλλακτικές πιθανές εκβάσεις ανά επιλογή.
- 558 εικόνες με έμφαση στη συνέπεια, το συναίσθημα και την αντίδραση.
- Μικρά αρχεία 320 px στην κανονική προβολή. Η μεγάλη εικόνα έως 1254 px φορτώνεται μόνο με πάτημα για μεγέθυνση.
- Χωρίς εκφώνηση. Προαιρετικές περιγραφές εικόνων, σημειώσεις θεραπευτή και μεγαλύτερα γράμματα.

Η εφαρμογή είναι στατική. Δεν διαθέτει λογαριασμούς και δεν αποθηκεύει στοιχεία παιδιών.

## Άλλες εφαρμογές ΣΥΝΟΙΔΑ
